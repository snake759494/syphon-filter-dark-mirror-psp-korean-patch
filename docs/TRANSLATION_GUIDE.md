# 번역 지침

- 외부 기계 번역을 쓰지 않고 직접 번역했습니다.
- 첩보 액션 분위기에 맞춰 무전 대사는 짧고 단호한 구어체로, 브리핑·정보 문서는 보고서체로 씁니다.
- 인명·조직명은 한글로 음역하고, 실제 총기 모델명·코드명은 영어 그대로 둡니다.
- 버튼 기호·제어 코드·서식 문자는 원문 그대로 유지합니다.
- **MRK 음성 자막은 원문 바이트 길이 안에** 들어가야 합니다(한글 1자 = 2바이트). 넘치면 `mrk_short.json` 에 줄인 번역을 넣습니다.
- 실행 파일 문자열(`boot.json`)도 원래 자리 길이를 넘을 수 없습니다.
- 화면 폭이 좁은 메뉴 항목은 짧은 말을 고릅니다.
- 쓸 수 있는 글자는 글꼴 페이지에 들어간 한글 음절, ASCII, ™ 입니다.
